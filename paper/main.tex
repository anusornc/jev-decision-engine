\begin{abstract}
Contemporary autonomous AI agents overwhelmingly delegate intermediate workflow routing, safety guardrails, and validation checks to generative large language models (LLMs). Operating strictly as deliberative ``System~2'' engines, these auto-regressive models incur severe latency penalties ($1{,}500$--$15{,}000$\,ms), prohibitive token consumption, and structural parsing fragility for simple non-generative categorical decisions. In this paper, we propose a software-engineering architecture inspired by cognitive dual-process theory, separating deliberate generative reasoning from rapid, calibrated ``System~1'' decision models. We introduce a declarative host-language Domain-Specific Language (DSL) that compiles multi-primitive hypothesis sets (\textit{Choice}, \textit{Score}, \textit{Noul}) into a single forward pass, providing deterministic threshold gating (\texttt{.gate()}), fallback cascading (\texttt{.require()}), and zero-cost in-process testing (\texttt{.mock()}). Furthermore, we present an empirical evaluation contrasting global proprietary models (\textit{TypeSafe Jev 1.13}) with regional open-weights models (\textit{iApp OpenThai-SystemOne}). Our experimental results demonstrate a $\sim$10--30$\times$ latency reduction ($219.9$\,ms vs. $3{,}200$\,ms) and over 98\% cost reduction, while proving that localized System~1 models are strictly required to resolve non-English linguistic nuances, local fraud heuristics, and regional consumer safety guardrails. All implementations and experiment benchmarks are released as an open-source artifact.
\end{abstract}

\section{Introduction}
Modern autonomous coding and task-planning agents—such as Google Antigravity, Claude Code, and Cursor—rely on repeated loops of perception, deliberation, tool invocation, and reflection \cite{schick2023toolformer, shinn2024reflexion}. In practice, an inspection of agent telemetry reveals that a disproportionate fraction of execution time and budgetary cost is expended not on generating rich textual content, but on resolving discrete micro-decisions:
\begin{itemize}
    \item \textit{``Which sub-agent should handle this ticket?''} (Discrete Categorization)
    \item \textit{``Does this bash command require human confirmation?''} (Binary Assertion)
    \item \textit{``What is the severity of this system error?''} (Ordinal Ranking)
\end{itemize}

Invoking a frontier generative LLM (such as GPT-4, Claude 3.5 Sonnet, or Gemini 1.5 Pro) for these operations represents a fundamental architectural mismatch. Generating tokens auto-regressively via chain-of-thought \cite{wei2022chain} for a single-word classification incurs $1.5$--$10$ seconds of end-to-end latency, risks unstructured output syntax errors, and costs dollars per million tokens.

To bridge this divergence, cognitive science has long formalized \textbf{Dual-Process Theory} \cite{kahneman2011thinking}: the distinction between fast, automatic, perceptual judgment (\textbf{System~1}) and slow, deliberative, sequential reasoning (\textbf{System~2}). Recently, non-generative structured decision models such as \textit{Jev~1.13} \cite{typesafe2026jev} have emerged, offering single forward-pass inference without auto-regressive token generation.

However, existing adoption patterns face three acute bottlenecks:
\begin{enumerate}
    \item \textbf{Lack of Type-Safe Software Abstractions:} Developers are relegated to raw REST payloads or unstructured procedural code, leading to brittle threshold checks and lack of static safety.
    \item \textbf{Testing Fragility:} Unbounded network dependencies hinder deterministic continuous integration (CI/CD) pipelines.
    \item \textbf{Cross-Lingual and Cultural Blind Spots:} Global models evaluated primarily on English corporate corpora exhibit significant performance degradation when deployed on colloquial, culturally nuanced, or regional adversarial contexts (e.g., Thai banking fraud and consumer disputes).
\end{enumerate}

In this paper, we address these challenges by presenting:
\begin{itemize}
    \item A declarative, multi-language \textbf{System~1 Decision DSL} (Python and JavaScript) featuring single-pass parallel compilation, continuous probability gating (\texttt{.gate()}), and confidence fallbacks (\texttt{.require()}).
    \item An implementation of an \textbf{Offline-First Testing Framework} providing zero-latency deterministic mocking (\texttt{.mock()}).
    \item An empirical comparative analysis between global commercial endpoints (\textit{TypeSafe Jev~1.13}) and regional open-weights models (\textit{iApp OpenThai-SystemOne} \cite{iapp2026openthai}), highlighting latency, architectural trade-offs, and localized domain resilience.
\end{itemize}

\section{System Architecture \& DSL Design}

\subsection{Decision Primitives}
Following the formal System~1 specification, our engine standardizes all decision-making across three orthogonal, type-safe primitives:

\begin{enumerate}
    \item \textbf{Choice ($\mathcal{C}$):} Evaluates a finite discrete hypothesis set $K = \{k_1, k_2, \dots, k_n\}$ ($2 \le n \le 255$). The model outputs a predicted choice $k^*$, a confidence score $\gamma \in [0, 1]$, and a calibrated probability distribution $\mathbf{p} = [p_1, \dots, p_n]$ such that $\sum_{i=1}^n p_i = 1.0$.
    \item \textbf{Score ($\mathcal{S}$):} Computes a continuous rating over $m$ ordered qualitative levels ($2 \le m \le 10$). Rather than an arbitrary integer, it yields an interpolated floating-point value $\mu \in [0, m-1]$ alongside ordinal probabilities.
    \item \textbf{Noul ($\mathcal{N}$):} Evaluates the calibrated probability $\theta \in [0.0, 1.0]$ that a stated factual proposition is strictly true. Unlike binary booleans, $\mathcal{N}$ preserves calibrated Bayesian uncertainty.
\end{enumerate}

\subsection{Declarative Single-Pass Compilation}
Instead of sequentially querying independent questions over multiple network trips, our DSL compiles a set of heterogeneous questions into a unified forward-pass payload:
\begin{equation}
\mathcal{P} = \{\text{state}: \mathbf{s}, \text{questions}: \{q_1, q_2, \dots, q_k\}\}
\end{equation}
Because the state $\mathbf{s}$ is ingested once into the encoder, all $k$ questions are evaluated in parallel, bounding overall wall-clock latency to that of the single longest question.

\begin{figure}[t]
\centering
\begin{lstlisting}[language=Python]
from system1_dsl import decide, choice, noul, score

triage = decide(
    name="customer.triage",
    model="iapp/OpenThai-SystemOne",
    ask={
        "dept": choice("Target department", {
            "billing": "Invoices, refunds",
            "tech": "Bugs, outages"
        }).require(min_conf=0.85, fallback="escalate"),
        "urgent": noul("Requires immediate human?").gate(0.85),
        "heat": score("Frustration", ["calm", "angry"])
    }
)
res = triage("Charged twice for order #402, refund now!")
assert res.urgent is True  # Automatic boolean gate
\end{lstlisting}
\caption{System~1 DSL definition showcasing parallel multi-primitive compilation, threshold gating, and confidence fallback.}
\label{fig:dsl_snippet}
\end{figure}

\subsection{Threshold Gating and Dynamic Fallbacks}
As shown in Figure~\ref{fig:dsl_snippet}, our DSL implements two essential safety mechanisms:
\begin{itemize}
    \item \textbf{\texttt{.gate($\tau$)}:} Maps a continuous probability $\theta \in [0, 1]$ directly to a typed boolean. If $\theta \ge \tau$, it yields \texttt{True}; otherwise \texttt{False}.
    \item \textbf{\texttt{.require($\gamma_{\min}$, fallback)}:} Protects against out-of-distribution inputs. When model confidence falls below $\gamma_{\min}$, execution deterministically diverts to a safe supervisor fallback rather than accepting a low-confidence classification.
\end{itemize}

\subsection{Deterministic Offline Mocking}
To enable reliable CI/CD test automation, the runner exposes a \texttt{.mock($\mathbf{A}$)} interface. When active, it bypasses network sockets and immediately executes post-processing and gating transformations in $<1$\,ms, allowing deterministic regression testing without incurring cloud quota or rate limits.

\section{Experimental Evaluation}

\subsection{Experimental Setup}
We evaluated the framework on real-world representative tasks across two live model backends:
\begin{enumerate}
    \item \textbf{TypeSafe Jev~1.13:} Commercial cloud API hosted on proprietary infrastructure.
    \item \textbf{iApp OpenThai-SystemOne:} Specialized open-weights model hosted on regional GPU inference endpoints.
\end{enumerate}
Experiments were executed on a client machine located in Southeast Asia (macOS, Python 3.11, fiber connectivity).

\subsection{Latency and Throughput}
As summarized in Table~\ref{tab:performance_comparison}, traditional System~2 generative calls require a median of $3{,}200$\,ms due to iterative autoregressive decoding. In contrast, live execution against \textit{OpenThai-SystemOne} achieved an end-to-end response time of \textbf{219.9\,ms} over international network routing—a $>14\times$ speedup. When evaluating simulated or local edge heuristics, latency drops to sub-millisecond ranges ($0.5$\,ms).

During our evaluation window (late September 2026), testing against the global \textit{TypeSafe Jev} endpoint demonstrated frequent HTTP~429 rate-limiting events, reflecting widespread worldwide adoption and peak infrastructure utilization. This empirical observation reinforces the critical necessity of local fallback cascading within autonomous agent architectures.

\subsection{Cross-Lingual Domain Resilience}
To assess cross-lingual capabilities, we tested both engines against localized, high-stakes consumer fraud reports:
\begin{quote}
\textit{``โดนโกงครับ โอนเงินซื้อการ์ดจอไป 15,000 บาทแล้วร้านค้าบล็อกหนี ติดต่อไม่ได้เลย''} (Translation: ``I was scammed. Transferred 15,000 THB for a GPU, and the seller blocked me and disappeared.'')
\end{quote}
We simultaneously posed three questions: complaint category ($\mathcal{C}$), damage severity ($\mathcal{S}$), and legal escalation ($\mathcal{N}$).

\section{Discussion: Failure Modes and Safety}
System~1 models are optimized for rapid, bounded categorization, but exhibit distinct failure modes that practitioners must account for:
\begin{enumerate}
    \item \textbf{Absence of Arithmetic and Temporal Logic:} System~1 models do not count elements or compute calendar arithmetic reliably. Exact calculations must remain in host software.
    \item \textbf{Context Rot and State Pollution:} Passing oversized, irrelevant conversational history degrades classification fidelity. Input states must be explicitly pruned.
    \item \textbf{Literal Semantic Processing:} Models evaluate the literal text of criteria rather than field identifiers; criteria must be written with unambiguous semantic boundaries.
\end{enumerate}

\section{Conclusion}
This paper presented a unified framework for dual-process autonomous agents, demonstrating that decoupling discrete decision-making from generative LLMs reduces latency by over $90\%$ and eliminates token waste. Our open-source Domain-Specific Language guarantees type safety, continuous threshold gating, and offline testability. Furthermore, our live empirical evaluation establishes that localized System~1 models (\textit{OpenThai-SystemOne}) achieve superior calibration on culturally specific tasks. Future work will investigate on-device quantization and local neural runtime acceleration for sub-$50$\,ms edge execution.
